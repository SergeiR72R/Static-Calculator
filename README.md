# Balkenrechner — онлайн-калькулятор балок (МКЭ)

Клиентское веб-приложение для расчёта прямых балок методом конечных элементов: однопролётные и неразрезные балки, консоли, балки Гербера, упругие опоры, осадки, загружения и сочетания по DIN EN 1990, шахматное загружение, огибающие, экспресс-проверки, пошаговый отчёт (KaTeX), экспорт PDF/CSV/DXF. Расчёт целиком в браузере, бэкенда нет, ограничений на число элементов нет.

Язык по умолчанию — немецкий; дополнительно английский, русский и иврит (переключатель в шапке, выбор хранится в `localStorage`).

### Иврит (RTL)

- `dir="rtl"` на `<html>` и `Direction.Provider` Radix (иначе вкладки Radix принудительно ставят `dir="ltr"`); отступы и выравнивание — логическими классами (`ms-*`, `pe-*`, `text-start`, `text-end`, `border-e`).
- Схема балки, эпюры, 3D-вид, формулы KaTeX и матрицы остаются слева направо (ось x вправо); подписи на иврите внутри SVG — `unicode-bidi: plaintext`.
- Числа: he-IL (десятичная точка). `Intl` ставит перед отрицательными числами невидимый знак LRM — он удаляется, а в интерфейсе числа с единицами обрамляются LRM, чтобы минус и «L = 10.00 m» не переставлялись.
- Формулы отчёта не содержат текста на иврите (текст внутри формул — по-английски, названия загружений — кодом категории). DXF для иврита подписывается по-английски (R12 не поддерживает RTL-текст).

## Команды

```bash
npm ci
npm run dev          # дев-сервер Vite
npm run build        # tsc (strict) + сборка в dist/
npm run lint         # ESLint, 0 предупреждений
npm test             # Vitest: ядро, единицы, сечения, i18n, DXF, CSV, отчёт
npm run test:e2e     # Playwright (сборка + preview на :4173)
npm run dxf:samples  # DXF-образцы в dxf-samples/ + ezdxf audit (нужен python3 + ezdxf)
npm run catalog      # пересобрать src/sections/catalog.json из размеров профилей
```

## Стек

TypeScript (strict), Vite 7, React 19, Tailwind CSS 4, Radix UI (tabs, popover, dialog, dropdown, switch, tooltip), zustand, KaTeX, lz-string. SVG-графика без chart-библиотек. Тесты: Vitest + fast-check, Playwright.

## Фирменный стиль

Оформление в стиле **promaintain** («Nah am Kunden. Nah am Projekt.»): фирменный синий `#004F7E` (основные кнопки, заголовки, акцентная шкала `accent-*`) и салатовый `#AFCB51` (полоса под шапкой, активные вкладки, прогресс мастера, эпюра M).

- `src/assets/promaintain-logo.png` — логотип со слоганом (мастер первого запуска, печатный отчёт, HTML-отчёт — встроен как data URI).
- `src/assets/promaintain-wordmark.png` — словесный знак без слогана (шапка, заголовок мастера); в тёмной теме — на белой подложке.
- Цвета задаются в `src/index.css` (`@theme`), константы бренда — в `src/ui/Brand.tsx`.

## Проекты и первый запуск

- При первом запуске на компьютере (в браузере ещё нет сохранённого проекта и приложение открыто не по ссылке) открывается мастер: основные настройки (язык, единицы, тема, знаки после запятой) → проект (название, исполнитель, описание) → расчётная схема (шаблон и длина; шаблоны задают только опоры и шарниры, без нагрузок) → сечение и материал → параметры расчёта → сводка.
- Выбор можно сохранить как настройки по умолчанию: следующий новый проект будет ими предзаполнен.
- Дальше при запуске открывается последний проект (автосохранение в `localStorage`, сброс на диск при закрытии или скрытии вкладки).
- Кнопка «Neues Projekt» в шапке (и «Datei → Neues Projekt…») открывает мастер без шага основных настроек. Текущий проект заменяется, его можно сохранить в JSON прямо из мастера.

## Расчётное ядро

- Плоский рамный элемент, 3 степени свободы в узле (u, w, θ), матрица 6×6 (EA, EI), матрица преобразования **T** (для балки T = I, готово для рам в v2). Эйлер–Бернулли или Тимошенко (Φ = 12EI/(G·A_s·L²), точные реакции защемления).
- Автоматическая сетка по характерным точкам (концы, опоры, шарниры, сосредоточенные нагрузки, начало/конец распределённых нагрузок, смена сечения), слияние точек ближе 1e-9 м.
- Сборка → разбиение на свободные и закреплённые DOF (без штрафа) → разложение Холецкого по ленте (тот же алгоритм, что и плотный Холецкий, но без структурных нулей) + одна итерация уточнения; оценка числа обусловленности κ₁ (Hager/Higham).
- **Шарниры** — двойной узел: общие u, w, раздельные θ_L / θ_R. Сосредоточенный момент в шарнире привязывается к левой или правой стороне. Шарнир на конце балки игнорируется с предупреждением, шарнир в заделке превращает её в шарнирно-неподвижную опору.
- Опоры: заделка, шарнирно-неподвижная, каток, ползун, упругая (k_u, k_w, k_θ), осадки Δu/Δw/Δθ (с привязкой к загружению).
- Усилия внутри элемента — точно из равновесия (концевые усилия + нагрузка участка); прогиб — эрмитова интерполяция + частное решение защемлённого элемента (для Тимошенко — точное интегрирование).
- Геометрическая изменяемость: кинематический анализ до разложения (дисков между шарнирами) с понятными сообщениями («нет закрепления по X», «два шарнира подряд без опоры», «балка не закреплена» …) и контроль ведущих элементов при разложении.
- Сочетания: пресеты 1,35·G + 1,5·Q, 1,0·G + 1,5·Q (ГПС) и 1,0·G + 1,0·Q (ГПЭ), редактируемые. Шахматное загружение для категории Q — огибающая по **всем** 2ⁿ вариантам загрузки пролётов, вычисляемая точно суперпозицией (max = база + Σmax(0, пролёт)).

## 3D-вид с тепловой картой

Под эпюрами — интерактивная 3D-модель балки (three.js, подгружается отдельным чанком). Каждый участок выдавливается из реального контура сечения, показаны опоры и шарниры. Раскраска на выбор: напряжение σ(x, z) = N/A + M·z/I (красное — растяжение, синее — сжатие, по высоте сечения), коэффициент использования η = |σ|/f_d (красный = 100 %), M, Q (V), |w|. Сечение для наглядности автоматически увеличивается (с подписью), можно показать деформированную форму. При наведении — значение в точке и общий визир с эпюрами.

## Элементы PERI

Тип сечения «Элемент системы PERI» (`src/sections/peri.ts`): при выборе элемента автоматически ставится материал и предлагается длина из каталога (выбор задаёт длину балки, «своя» — любая длина).

| Элемент | Характеристики | Проверка | Длины по каталогу, м |
|---|---|---|---|
| GT 24 (C24) | пояса 80×60, I = 8064 см⁴ (EI = 887 кН·м²), 5,9 кг/м | perm M = 7,0 кН·м, perm Q = 13,0 кН, perm R = 28,0 кН | 0,90…6,00 через 0,30 |
| VT 20K (C24) | пояса 80×40, I = 4181 см⁴ (EI = 460 кН·м²), 5,9 кг/м | perm M = 5,0 кН·м, perm Q = 11,0 кН, perm A = 11,0 кН (край), perm B = 22,0 кН (промежуточная) | 1,45…5,90 (12 длин) |
| SRU U120 (S235) | 2×U120 нетто: A = 28,2 см², I = 696,98 см⁴, 26,6 кг/м | M_Rd / N_Rd / V_Rd зон A и B + взаимодействие PERI (a_w, w_w) | 0,72…5,97 (16 длин) |
| RCS (S355) | 2×U200 нетто: A = 56,38 см², I = 3576 см⁴, 52,6 кг/м | M_Rd = 132,7 кН·м, N_Rd = 1820 кН, V_Rd = 432,91 кН + взаимодействие | 1,48…9,98 (6 длин) |

- Источники: SRU и RCS — PERI Bemessungsinformationen «RCS/VARIOKIT Connections» (разд. 4.1, 4.10); GT 24 и VT 20K — опубликованные данные PERI. I балок вычислен по поясам и совпадает с EI PERI при E = 11 000 Н/мм². Длины VT 20K и perm Q GT 24 сверить с актуальной документацией PERI.
- GT/VT: допустимые значения (perm F = R_d/1,5) сравниваются с фактическими нагрузками — основа: сочетания ГПЭ (1,0·G + 1,0·Q). Опора на конце балки — «крайняя», остальные — «промежуточные».
- SRU/RCS: расчётные сопротивления сравниваются с огибающей ГПС; формулы взаимодействия n–m_y, v–m_y, n–v, n–v–m_y (последние три при v > 0,5). Устойчивость (сжатие) не проверяется.
- Для участков из элементов PERI общая проверка σ ≤ f_d и τ не выполняется; собственный вес — по массе из каталога.

## Соглашения о знаках

- x вправо, z (прогиб) вниз; угол силы от +x по часовой стрелке (90° = вниз); q > 0 вниз; M > 0 и θ = dw/dx по часовой стрелке.
- Усилия по DIN: N > 0 — растяжение; V > 0 на положительной грани в +z; M > 0 — растянуто нижнее волокно.
- Реакции показываются как силы, действующие на балку: R_x → +, R_z ↑ +, M_R ↻ +. В отчёте реакции в глобальной системе (z вниз), пересчёт указан.
- Переключатель «растянутое волокно снизу/сверху» меняет сторону, на которой рисуется положительный M (по умолчанию — со стороны растянутого нижнего волокна).

## Проверки (экспресс-оценка, не проверка по нормам)

- Прочность: σ = |N|/A + |M|/W для верхнего и нижнего волокна, f_d = k_mod·f_k/γ_M; основа — огибающая сочетаний ГПС.
- Опционально касательные напряжения τ = V·S/(I·b).
- Прогиб по пролётам (L/250) и консолям (L/125) по сочетаниям ГПЭ; абсолютный прогиб w.

## Тесты

- Эталонные схемы §9.1 (консоль, шарнир–шарнир, заделка–заделка, заделка–шарнир, 2- и 3-пролётные, Гербер, сила под углом, трапеция, момент в пролёте, пружины k→∞/k→0, осадка, механизмы) — относительная погрешность < 1e-6.
- Property-based (fast-check): 300 случайных моделей, ΣF_x, ΣF_z, ΣM с невязкой < 1e-9·ΣP; непрерывность усилий.
- Сочетания/огибающие (сравнение с явным перебором вариантов), ручной расчёт ↔ МКЭ.
- Единицы (round-trip без дрейфа), сечения (формулы и выборочно сортамент), локализация (одинаковые наборы ключей и плейсхолдеров, все ключи из кода существуют), DXF (структура, слои, коды групп, кодировки), CSV, отчёт (валидный KaTeX во всех языках).
- CI: `ezdxf audit` всех DXF-образцов (36 файлов, 0 ошибок и 0 исправлений) и их открытие в LibreCAD (`librecad dxf2pdf` под xvfb).
- E2E: язык по умолчанию, «шаблон → изменить нагрузку → эпюры обновились», undo/redo, смена языка, скачивание DXF и JSON, открытие JSON, восстановление по ссылке, сообщение о механизме, валидация поля, отчёт, перетаскивание опоры.

Сборка статическая (`dist/`, относительный `base`), подходит для любого статического хостинга:

## Известные ограничения и отклонения

- Сверка с SkyCiv Free не автоматизирована; результаты сверяются с аналитикой.
- Русский текст в DXF записывается корректно (ANSI_1251, ezdxf читает его без ошибок), но стандартный шрифт LibreCAD не содержит кириллических глыфов — надписи там отображаются заменителями. В AutoCAD зависит от шрифта стиля STANDARD.
- Шахматное загружение для σ в огибающей даёт консервативную оценку (|N|max/A + |M|max/W).
- v1: только прямая балка вдоль x; рамы, линии влияния и нормативные проверки — в планах (§11).
