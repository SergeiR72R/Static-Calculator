# Журнал решений: расчёт лесов PERI UP Flex

Каждое решение по модели и расчёту записывается сюда: что решили, почему (документ, сверка, указание
заказчика), что это дало в цифрах и чем решение можно отменить (настройка). Цель: при новой сверке с
PERI ForceControl (PFC) видеть, какое решение что сдвинуло, и возвращаться к ним осознанно.

Статусы: **действует** · **пересмотреть** (есть новые данные против) · **открыто** (решение не принято).
Источник: **Допуск** = Z-8.22-863 (2025), **PFC** = отчёты PERI ForceControl 18_007, 18_011, 18_012,
18_013, **Заказчик** = указание пользователя.

## Решения

### Р-001 · 2026-11-10 · Розетки 6 мм на всех стойках · изменено решением Р-021
- **Решение:** узлы считаются с параметрами 6-мм розетки (Rosette-2) для всех стоек, независимо от
  артикула (`rosette6`, по умолчанию да).
- **Почему:** если на площадке неизвестно, какие стойки будут, допуск велит брать невыгодный вариант;
  при 8 мм модель 18_011 была заметно жёстче PFC (A ±x 18 мм вместо 24).
- **Против (2026-11-16):** несущая способность UBK в PFC 18_012 ≈ 9,7 кН — это значение допуска для
  8-мм розетки (UBK 75/200: 9,73 кН; у 6 мм 6,09 кН). PFC, видимо, берёт розетку по артикулу (UVR —
  8 мм) хотя бы для проверок. См. О-1.
- **Настройка:** `ModelOptions.rosette6`.

### Р-002 · 2026-11-10 · Стойка над стойкой с зазором ≥ 40 см стоит на балке
- **Решение:** при зазоре 40 см и больше между ними принята балка конструкции, верхняя стойка опирается
  на неё; при меньшем зазоре — настил, нагрузка идёт на нижнюю стойку через пару шпинделей.
- **Почему:** чертежи C411 / C417. · **Статус:** действует.

### Р-003 · 2026-11-10 · Настилы без жёсткости, собственный вес 0,30 кН/м²
- **Почему:** как в PFC. · **Статус:** действует.

### Р-004 · 2026-11-16 · Люфт диагоналей по умолчанию выключен · действует (см. О-1)
- **Решение:** диагонали работают без люфта (`diagSlack`, по умолчанию нет).
- **Почему:** со включённым люфтом всех диагоналей смещения 18_011 получались 68 мм вместо 24 (PFC).
- **Против (2026-11-16):** допуск п. 3.2.3.2 требует для UBK люфт 1,2 см (UBS 0,1 / 0,3 см, UBL и UBH
  0,2 см). В PFC у диагоналей нелинейные диаграммы в шарнирах; силы в UBK 18_012 у PFC ≤ 1,41 кН, у
  нас до 5,3 кН. Кроме того, текущий алгоритм выключает диагональ насовсем после 4 переключений — это
  может искусственно размягчать каркас. См. О-1.

### Р-005 · 2026-11-16 · UBK по приложению A (A.1 / A.2, эксцентричная головка)
- **Решение:** по умолчанию характеристики UBK из таблиц A.1 / A.2 со смещённой головкой
  (e_x 8,3 см, e_y 3,6 / 5,0 см); альтернатива — таблица 15.
- **Почему:** допуск разрешает A.1 / A.2 при известном расположении UBK; калибровка 18_013.
- **Настройка:** `ModelOptions.ubk` / в интерфейсе «Модель UBK». · **Статус:** действует.

### Р-006 · 2026-11-16 · Стыки стоек не работают на растяжение
- **Решение:** стык стоек (втулка) при растяжении раскрывается (`spliceNoTension`, по умолчанию да).
- **Почему:** шарнир «Traggerüst» в PFC — нелинейный по оси, изгиб жёсткий. · **Статус:** действует.

### Р-007 · 2026-11-16 · Оторвавшаяся опора освобождает все три перемещения
- **Почему:** как в PFC («abgehobene Lager» без Px / Py / Pz); число оторванных опор 18_013 совпало
  (2 / 6). · **Статус:** действует.

### Р-008 · 2026-11-16 · Начальные искривления стоек
- **Решение:** местные L/250, общие L/500, крен 1/200 — эквивалентными нагрузками (`bows`).
- **Почему:** как в PFC («AI», «SI»). · **Статус:** действует.

### Р-009 · 2026-11-16 · Сочетания A / R / S как в PFC
- **Решение:** A — γ 1,5 (рабочий ветер 0,20 кН/м²); R — 1,5 G + максимальный ветер + доля Q; S —
  0,9 G + максимальный ветер. · **Статус:** действует.

### Р-010 · 2026-11-16 · Балласт из тел чертежа · Заказчик
- **Решение:** блоки с атрибутом «Gewicht» (× FAKTOR) или объём × плотность по названию становятся
  постоянной нагрузкой на ригели / балки под ними; на настилах — по правилу рычага между ригелями.
- **Почему:** «Распознавай баласт автоматически по габаритам». · **Настройка:** `planLoads`.

### Р-011 · 2026-11-16 · Верхняя платформа не нагружает леса · Заказчик
- **Решение:** доски / тела выше лесов (платформа 18_013, считается отдельно) нагрузкой не являются.

### Р-012 · 2026-11-16 · Труба крепления подъёмника — не анкер
- **Решение:** труба с хомутами на двух и более стойках — связь, а не анкер.
- **Почему:** 18_007 («в модели нет ничего похожего на анкеры»). · **Статус:** действует.

### Р-013 · 2026-11-16 · 18_007 вместо 18_010 · Заказчик
- Калибруем по 18_007; 18_010 не используется.

### Р-014 · 2026-11-16 · Все детали чертежа — в модели · Заказчик
- **Решение:** у каждой детали фиксируется роль в модели (стержень, настил, стык, только вес, входит в
  вес другой детали, несущая вне каркаса, без веса, не в модели); итог — в расчёте и в отчёте.
- **Почему:** «Нельзя чтобы что-то терялось при импорте». 18_007 / 011 / 012 / 013: потерь нет.

### Р-015 · 2026-11-16 · Чтение DXF в системе координат объекта (OCS)
- **Решение:** окружности, полилинии и вложенные блоки внутри блоков переводятся из OCS их
  направления выдавливания.
- **Почему:** розетки соединителя ULS Flex читались на −0,125 / −0,625 м вместо +0,125 / +0,625;
  бортовые доски лежали плашмя; шпиндели во вложенных блоках смотрели не туда (C411).

### Р-016 · 2026-11-16 · Розетки соединителей ULS Flex и хомутовые розетки UEV
- **Решение:** ригели и диагонали на розетках соединителя ULS Flex висят на ферме (узел розетки,
  стойка соединителя Ø48,3 × 3,2); хомутовая розетка UEV даёт розетку на стойке на своей высоте.
- **Почему:** 18_011 (платформа на +4,38 м), D18. Эффект 18_011: A ±x 22,0 / 22,4 → 23,3 / 23,1 мм.

### Р-017 · 2026-11-16 · UK 70 (103737) — стык балок SRU / RCS · Заказчик
- **Решение:** балки, заканчивающиеся в UK 70, жёстко соединены (неразрезная балка).
- **Почему:** «103737 это коннектор двух RCS/SRU». Эффект 18_012: A +x 15,3 → 12,6 мм (PFC 11,5),
  R ±x 25,0 / 22,5 → 23,3 / 18,4 мм (PFC 17,4). Вес UK 70 в базе неизвестен.

### Р-018 · 2026-11-16 · Ригель никогда не шарнир · Заказчик
- **Решение:** каждый конец ригеля — клиновая головка в розетке (стойка, UEV, соединитель Flex,
  конец консоли, UHA): полужёсткие пружины допуска и проверка узла. Нет розетки в чертеже на этой
  высоте — розетка принимается (примечание).
- **Почему:** «У нас в принципе не может быть ригелей-шарниров».

### Р-019 · 2026-11-16 · Ригель, закреплённый одним концом · Заказчик
- **Решение:** без настилов — ограждение (консоль, только собственный вес, без нагрузок от
  настилов); с настилами — на втором конце забыт узел: предупреждение при импорте и закрепление
  второго конца в предполагаемой розетке для расчёта.
- **Почему:** «Ригели, зафиксированные только одним концом, могут быть только как guardrails без
  нагрузок»; «…с деками на нём — проектировщик забыл фиксатор, говорить при импорте и фиксировать с
  двух сторон». C411: 6 таких ригелей; D18: 24 ограждения.

### Р-020 · 2026-11-16 · Головной шпиндель нижней стойки — часть звена между стойками
- **Решение:** в паре шпинделей через настил головной шпиндель нижней стойки входит в стержень
  звена (с весом). · **Почему:** иначе он числился вне каркаса (C411: 72 шпинделя).

### Р-021 · 2026-11-16 · Прочность узлов и диагоналей — по артикулу стойки, жёсткость — 6 мм · Заказчик
- **Решение:** пружины узлов, жёсткость и люфт диагоналей — по 6-мм розетке (как Р-001); несущая
  способность узлов «ригель–розетка» (табл. 11 / 12, ур. 1, 7, 8) и диагоналей UBK / UBS — по артикулу
  стойки (табл. 6: UVR / UVH / UVB 24 / 49 — 8 мм; UVB 25 / 50, «-2» — 6 мм). Розетки не на стойках
  (соединитель Flex, UEV, UHA, консоль) — 6 мм.
- **Почему:** PFC 18_012 проверяет UBK с несущей способностью 8-мм розетки (≈ 9,7 кН); смещения при
  этом лучше совпадают с жёсткостью 6 мм. Выбор заказчика из трёх вариантов.
- **Эффект:** η UBK 18_012 0,86 → 0,54 (PFC 0,14); 18_011, 18_013, 18_007 — η узлов почти без изменений
  (там стойки «-2» / UVB 50 или узлы не определяющие); смещения не меняются.
- **Настройка:** `ModelOptions.capByArticle` / в интерфейсе «Несущая способность узлов и диагоналей».

### Р-022 · 2026-11-16 · Где проверяется труба стойки · Заказчик
- **Решение:** в узле с ригелями трубу стойки отдельно не проверяем — её учитывает проверка узла по
  ур. 1 (α·I_A + I_S, I_S — труба в узле). Нижняя стойка на опоре проверяется в сечении 10 см над
  шарниром (опорная плита шпинделя), как PFC; прочие концы без ригелей — как раньше.
- **Почему:** PFC 18_007 и 18_013 проверяют UVB по DIN 4420-1 табл. 7 с M / V = 10 см при разных выпусках
  шпинделя (4,8 и 6,8 см) — фиксированное правило PFC. Его η UVB по ур. 25 — это стык стоек на сжатие
  (N / 100 кН), у нас проверка «joint».
- **Эффект 18_007:** труба UVB 24 η 0,59 → 0,40 (M 114,7 → 68,5 кНсм, PFC 74); узел UVB по ур. 1 — 0,61.
- Закрывает О-5.

### Р-023 · 2026-11-16 · Сочетание S сверяется только по устойчивости
- **Решение:** в сочетании S сравниваем с PFC реакции опор и число оторванных опор; смещения S не
  сравниваем (см. О-4: у PFC они не зависят от вертикальной нагрузки и отрыва). Модель не меняется.

## Открытые вопросы

### О-1 · UBK 18_012: η 0,86 у нас против 0,14 у PFC · несущая способность решена (Р-021), сила открыта
Расхождение складывается из двух частей.

**1. Несущая способность.** PFC берёт для UBK ≈ 9,7 кН. Это значение допуска для 8-мм розетки (UBK
75/200: 9,73 кН), у нас 6,09 кН (6 мм, Р-001). Проверено по нескольким UBK отчёта: N / η = 9,3 … 9,7 кН.

**2. Сила.** У PFC во всех UBK |N| ≤ 1,41 кН, у нас до 5,3 кН. Исследование 2026-11-16 (18_012,
сочетание A ±y, поперечная сила по y через горизонтальное сечение лесов):

| Вариант модели | A ±y, мм | A ±x, мм | Доля UBK в поперечной силе внизу | max N UBK, кН | η UBK |
|---|---|---|---|---|---|
| сейчас: 6 мм, без люфта | 31,2 / 29,0 | 12,6 / 10,5 | 73 % | 5,3 | 0,86 |
| 8 мм, без люфта | 27,4 / 26,6 | 12,0 / 9,6 | – | 5,4 | 0,56 |
| 6 мм, люфт по допуску (UBK 1,2 см) | 68,8 / 66,4 | 18,8 / 15,8 | 24 % | 2,6 | 0,32 |
| 8 мм, люфт по допуску | 57,7 / 58,1 | 18,5 / 15,1 | – | 3,0 | 0,24 |
| балки SRU защемлены на головках шпинделей | без изменений | без изменений | – | – | – |
| PFC | 30,4 / 29,2 | 11,5 / 8,1 | мала | 1,41 | 0,14 |

- Допуск п. 3.2.3.2: для UBK по таблице 15 — люфт 1,2 см; альтернативно таблицы A.1 / A.2 со
  статической моделью приложения A (с. 20 / 21). PFC использует модель приложения A (нелинейные
  диаграммы в шарнирах головки).
- Без люфта удлинения всех UBK в A ±y ≤ 3,9 мм, то есть с люфтом 1,2 см ни одна UBK при таком
  перекосе не включилась бы. Наш алгоритм люфта не виноват: «застрявших» выключенных диагоналей
  3 из 119.
- Вывод: у PFC рамная работа стоек (узлы ригель–розетка, опирание) примерно вдвое жёстче нашей, и
  UBK почти не работают. У нас ту же жёсткость дают UBK без люфта, поэтому совпадают смещения, но
  силы в UBK завышены (в запас). Что именно жёстче у PFC, по отчёту установить нельзя: диаграммы
  шарниров в нём не напечатаны.
- Несущая способность: решено Р-021 (η 0,86 → 0,54). Сила в UBK остаётся выше PFC (≈ 3,7 раза):
  у PFC рамная работа стоек жёстче нашей; причина по отчёту не установлена.

### О-4 · 18_013 S: 124 / 134 мм против 64 · закрыто: смещения S у PFC не сравнимы
- **PFC:** смещения S совпадают с R при разной вертикальной нагрузке и разном числе оторванных опор.
  18_013: G 270 кН (S) против 451 (R), ux 63,78 / 64,78 мм, повороты φx 3,900 / 3,900 и φy 11,700 / 11,700
  мрад, uy 1,42 / 1,42 — в тех же стержнях. 18_012: G 196 / 327 кН, ux −17,87 / −17,88, uy 10,34 / 10,34,
  −10,67 / −10,67 мм. Физически при меньшей вертикальной нагрузке и большем отрыве перемещения не могут
  совпадать до сотых; выдача смещений PFC для S, по-видимому, не отражает собственный расчёт S.
- **Наша модель, 18_013, ±x (2026-11-16):**

| Вариант | R | S |
|---|---|---|
| как есть (отрыв опор, стыки без растяжения, II порядок) | 63,7 | 124,4 |
| стыки с растяжением | 37,8 | 120,4 |
| I порядок | 58,6 | 109,8 |
| без погиби | 65,7 | 124,1 |
| опоры держат растяжение | 63,4 | 90,9 |
| опоры держат растяжение и стыки с растяжением | 32,9 | 32,4 |
| PFC | 64,9 | 63,9 |

- Без обеих нелинейностей S = R, как и должно быть при одном ветре. Большие смещения S у нас — от
  качания башен на подветренных рядах (подъём наветренной опоры до 11,6 мм) и раскрытия стыков.
  Реакции рядов и число оторванных опор в S с PFC совпадают (0 / 86,5 / 0 / 182,2 против 0 / 81,8 / 0 /
  188,7; 18 / 18).
- **Решение (Р-023):** в S с PFC сравниваем только устойчивость — реакции и отрыв опор; смещения S не
  сравниваем. Модель не меняем.

### О-5 · 18_007: место проверки трубы UVB · закрыто решением Р-022
- Мы проверяем у розетки (плечо 0,17 м), PFC — примерно 0,10 м над шпинделем. Предложение: трубу
  проверять вне розетки, узел — по уравнению 1 допуска.

### О-6 · 18_007: расположение балласта (91 кН на 14 нижних UHV — допущение) · ждёт данных
